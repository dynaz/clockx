# Floating Clock

ต้นแบบ Android สำหรับแสดงเวลาจริงจากเครื่องทับหน้าแอปอื่นขณะใช้ปุ่มแคปหน้าจอของระบบ รองรับ Android 8.0 ขึ้นไปตามการตั้งค่าโปรเจกต์ หน้าตั้งค่าเป็นภาษาไทยและใช้เวลาแบบ 24 ชั่วโมง

## เปิดโปรเจกต์

1. แตก ZIP แล้วเปิดโฟลเดอร์ `FloatingClock` ใน Android Studio
2. ติดตั้ง Android SDK Platform 35, Android SDK Build-Tools 35.0.0 และตั้ง Gradle JDK เป็น Java 17 ขึ้นไป
3. ตั้ง Gradle distribution เป็น Gradle 8.11.1 หากใช้ Gradle จากเครื่อง ให้รัน `gradle assembleDebug` ที่รากโปรเจกต์
4. กด Run เพื่อติดตั้งลงเครื่อง Android ที่เปิด USB debugging หรือเลือก Build APK ใน Android Studio ไฟล์ debug APK จะอยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

## ทดสอบบน Samsung Galaxy Z Fold5

1. เปิดแอป กด **อนุญาตให้แสดงทับแอปอื่น** แล้วเปิดสิทธิ์ให้ Floating Clock เมื่อกลับเข้ามาให้กด **เปิดนาฬิกาลอย**
2. ลากนาฬิกาไปที่มุมที่ต้องการ เปิด Chrome แล้วกดปุ่มด้านข้างพร้อมปุ่มลดเสียง ตรวจใน Gallery ว่านาฬิกาติดในรูป
3. ลองปิดวินาที เปิดตัวเลขขนาดใหญ่ และล็อกตำแหน่ง เมื่อเปิดล็อกให้ลองแตะลิงก์ตรงตำแหน่งที่นาฬิกาทับอยู่
4. ลองซ้ำบนจอฝาพับ จอด้านใน และแนวนอน จากนั้นกลับมากด **ปิดนาฬิกาลอย**

การที่นาฬิกาติดในภาพขึ้นอยู่กับพฤติกรรมการแคปของเครื่องและหน้าจอปลายทาง บางแอปซ่อนหน้าต่างลอยหรือบล็อกการแคปหน้าจอ ต้นแบบใช้ระบบแคปของเครื่องและใช้เวลาจากนาฬิการะบบโดยตรง
